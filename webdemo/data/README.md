# webdemo/data — 공공데이터 CSV 놓는 곳

여기에 놓은 CSV를 `../index.html`이 읽어 최근접 시설을 안내한다.
**원본 CSV는 용량이 커서 커밋하지 않는다**(저장소 `.gitignore`의
`webdemo/data/*.csv`). 각자 아래 절차로 내려받아 이 폴더에 두면 된다.

## 다운로드 절차 (공공데이터포털)

1. https://www.data.go.kr 접속 (다운로드만 하면 회원가입 불필요한 경우가
   많다)
2. 아래 표의 검색어로 검색 → "표준데이터" 또는 파일데이터의 **CSV** 다운로드
3. 내려받은 파일을 아래 "저장 파일명"으로 바꿔 이 폴더에 저장
4. 첫 줄(헤더)의 실제 컬럼명을 확인하고, 다르면 `../index.html`의
   `FACILITY_SOURCES`를 실제 컬럼명에 맞춘다

인코딩 주의: 포털 CSV는 EUC-KR(CP949)인 경우가 많다. `index.html`이
EUC-KR도 자동 처리하지만, 엑셀로 열었다 저장하면 형식이 바뀔 수 있으니
**내려받은 원본을 그대로** 두는 것을 권장한다.
